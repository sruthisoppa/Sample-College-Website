# 🎓 Sample College Website

This is a **Sample College Website** project built using **HTML** and **CSS**. It is a static website designed to showcase the basic layout and sections of a typical university portal, using SRM University AP as an example.

---

## 🌐 Website Features

- 🏫 **Homepage** with university title and animated header
- 📸 **Image Gallery** showcasing university visuals
- 🧑‍🎓 **Student Section** with a form to view profile
- 📝 **Admissions Section** placeholder
- 🏕️ **Campus Life** with image gallery
- 📅 **Events Section** placeholder
- 📞 **Contact Section** with university email and external link
- 💼 **Careers Section** with recruitment message
- 🏗️ **Infrastructure Section** with images and description
- 🔍 **Search bar** for information
- 📋 **Responsive layout** using simple CSS animations (slide, pulse, fade)
- 📊 **Team members table** styled with hover effects

---

## 💻 Technologies Used

- HTML5
- CSS3 (with animations and layout styling)
